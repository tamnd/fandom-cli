Each guide is built around a job rather than a command.
They assume you have run the [quick start](/getting-started/quick-start/).

- [Browsing a wiki](/guides/browsing-a-wiki/) — search, list, and explore articles using the Fandom v1 API.
- [Fetching a full article](/guides/full-article/) — get wikitext, infobox fields, link graphs, and categories with the `page` command.
- [BFS full-wiki crawl](/guides/bfs-crawl/) — use `allpages` and `page` together to reconstruct an entire wiki without missing any page.
- [Discovering wikis](/guides/wiki-discovery/) — find wikis by keyword or content hub.
