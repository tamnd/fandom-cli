What shipped in each release, newest first.
Every tagged version produces archives for Linux, macOS, Windows, and FreeBSD, Linux packages (deb, rpm, apk), a multi-arch container image on GHCR, and entries for the package managers.
Binaries are pure Go with no runtime dependencies.
